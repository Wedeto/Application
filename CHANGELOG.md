# Changelog

## 1.1.0

- Add support for PHP 8.1 through PHP 8.5.
- Retain support for PHP 7.4 while explicitly excluding PHP 8.0.
- Update all Wedeto dependencies to their PHP 8-compatible 1.1 releases, including Util 1.1.6, HTTP 1.1.2, I18n 1.1.1, and DB 1.1.1.
- Update the test suite to PHPUnit 9.6.
- Update the bundled jQuery from 2.2.4 to 3.7.1 to resolve known XSS vulnerabilities.
